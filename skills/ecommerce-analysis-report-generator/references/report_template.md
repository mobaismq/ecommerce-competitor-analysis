# 分析报告输出模板

本模板用于“电商竞品分析报告生成”skill。实际报告必须替换为真实数据结论，不保留示例占位。

## 标题

```markdown
# {商品名或关键词}竞品分析报告
```

标题不确定时使用“竞品分析报告”，并在数据源概览中说明商品名缺失。

## 一、数据源可用性概览

| 数据源 | 状态 | 有效信息 | 局限 |
|---|---|---|---|
| 商品标题 | 已提供/未提供 | 标题关键词、品类、标题卖点 | 缺失时标题模块信息不足 |
| 主图 | 已提供/未提供 | 首屏卖点、视觉风格、人群暗示 | 缺失时无法判断主图表达 |
| 详情图 | 已提供/未提供 | 功能参数、演示方式、场景 | 缺失时功能细节不足 |
| 用户好评 | 已提供/未提供 | 已满足诉求、正向卖点 | 缺失时真实满意点不足 |
| 用户差评 | 已提供/未提供 | 未满足诉求、痛点 | 缺失时风险判断不足 |
| 问大家 | 已提供/未提供 | 购买犹豫点、决策问题 | 缺失时购前疑虑不足 |

数据源少于 2 类时，在概览后提示“当前数据不足，仅能输出初步分析”。

### 关键词与卖点表达

| 关键词/卖点 | 类型 | 印证来源 | 置信度 | 运营判断 |
|---|---|---|---|---|

标题缺失时保留本模块，并写“因未提供商品标题，本模块无法拆解标题结构”。

## 三、商品核心卖点

先给卖点总判断：哪些是核心卖点，哪些只是素材侧出现但用户侧未验证。

| 优先级 | 卖点 | 类型 | 印证来源 | 置信度 | 代表性证据 | 运营动作 |
|---|---|---|---|---|---|---|
| 核心/重要/补充 |  | 功能/性能/品质/价格/服务/场景/人群 |  |  |  | 主图强化/详情页展开/标题前置/客服答疑 |

排序规则：

- 核心卖点：3 类及以上数据源印证，或图片强表达且评价强验证。
- 重要卖点：2 类数据源印证。
- 补充卖点：仅 1 类数据源出现，必须标低置信度。

### 已被满足的诉求

| 诉求 | 满足证据 | 运营利用方式 |

### 未被满足的诉求与痛点

| 痛点 | 痛点归因 | 严重程度 | 印证来源 | 置信度 | 改进方向 |
|---|---|---|---|---|---|
|  | 产品层面/预期层面 | 高/中/低 |  |  |  |

严重程度判断：

- 高：多条差评或问大家反复提及，且影响购买决策或退货。
- 中：有明确负面反馈，但集中在局部体验。
- 低：偶发、个体偏好或可通过说明降低预期落差。

## 八、分析局限与建议

用 3-6 条短句输出：

- 当前报告的主要数据局限。
- 下一步最应该补充的数据。
- 对标题、主图、详情页、商品优化、客服答疑的优先建议。

## 置信度标注

| 标注 | 判定 |
|---|---|
| 【多源印证】 | 3 类及以上数据源支持 |
| 【双源印证】 | 2 类数据源支持 |
| 【单源推断】 | 仅 1 类数据源支持，需注明置信度较低 |

同一来源内多条评价只能增强频次判断，不能替代多个数据源。
