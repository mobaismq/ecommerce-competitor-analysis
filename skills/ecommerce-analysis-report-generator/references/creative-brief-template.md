# 主图与详情页内容策划

用途：让运营、美工和作图工具根据真实竞品证据制定我方主图、详情页脚本。

- 按同一采集关键词的商品批次生成一套内容方向；每条发现注明具体商品和证据。不同品类不得混写。同店和重复图片不作为独立市场证据。
- 固定输出5张主图、8屏详情页，每张只解决一个购买问题。包含任务、文案草案、画面安排、来源、待补素材、可交给作图工具的画面简报。
- 首图交代品类与适用范围；中间图片依次展示实物、结构、可核实的卖点、规格与选购；详情回答“适不适合、凭什么、怎么选、怎么用”。根据实际品类调整，避免每张图重复一句卖点。
- 当前只有竞品资料，没有我方商品资料。文案保留[我方品牌]、[已核实规格]等字段。不得将竞品品牌、证书、参数、价格和功能承诺改写为我方事实。生成提示词不能要求伪造检测、疗效、试验结果或买家见证。
- 优先使用已完成的视觉/OCR观察、评价原文、标题和问答。图片看不到的参数不猜。缺失SKU/问答明细时如实标记；记录数量不等于完整明细。
- 好评、差评、混合反馈都要查看。品类不符、重复模板、价格或店铺错配的评价不作为核心依据，可在risks记录。收入、年龄、性别缺乏直接证据时不推断；宠物食品的使用主体是宠物，购买主体是饲主。
- 每个脚本都引用实际提供的evidenceIds；来源ID只能从资料列表中选，不能引用模板示例。没有证据时留空并在requirements说明补证，不能编造来源。
- insights是竞品发现而非已确认的我方优势；每条都要落到可执行的内容动作。不要声称推荐方案已经提高点击率或转化率。
- risks写真实样本边界、缺失信息和冲突；missingMaterials列出开拍、排版和发布前需要补齐的我方素材。
