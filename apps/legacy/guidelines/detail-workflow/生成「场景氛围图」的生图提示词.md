# 生成「场景氛围图」的生图提示词

按以下要求直接输出「场景氛围图」的生图提示词。

**要求：**

1. 本提示词作为独立节点使用，仅读取《平台品类规则》的「详情页总规划」和「场景氛围图」规划，必须使用其中的「全局视觉系统」「核心视觉」「背景/风格」「画面策略」「人物/道具建议」「平台规则」「图位文案」「产品角度/景别」「比例建议」「协同要求」；不重新规划模块。

2. 本模块负责展示真实生活空间、使用氛围和目标人群代入，必须与首屏主视觉做出区分，不重复首屏的同一场景、同一角度、同一人物动作和同一文案。

3. 场景必须符合日用百货类型，只能选择1个最适配真实场景。清洁用品可选厨房、浴室、客厅、桌面清洁；收纳用品可选衣柜、玄关、厨房、冰箱、浴室柜、桌面；餐厨器皿可选备餐、清洗、沥水、台面收纳、上桌；浴室用品可选洗漱台、淋浴区；家居小物可选卧室、客厅、办公桌、宿舍；一次性用品可选家庭备货、外出取用、聚会准备。

4. 画面采用单场景满铺大图，优先左文右景、右文左景、上文下场景或主体旁留白，不做分屏、小窗环绕、场景矩阵或信息卡堆叠。

5. 场景必须有具体动作或结果，不做无人空场景静物堆砌。人物/手部动作必须与商品状态一致：喷洒、擦拭、取用、悬挂、折叠、开合、收纳、清洗、沥水、安装、拿取等动作需符合实物结构，不得虚构额外配件。单场景画面必须铺满画布，上下左右不留大面积空白，不生成外框、白边、模板留白或纯色空底。

6. 文字必须使用《平台品类规则》中本模块的「图位文案」，必须使用「主标题 + 副标题 + 场景标签/短卖点」结构，主标题和副标题不得省略、合并或只输出标签。主标题和副标题不得有色块底/卡片底/胶囊底/大面积半透明底，文字放在低细节负空间或自然留白区；仅场景标签可用小胶囊或细线框，但不得承托主副标题，不得压住产品主体、人物脸部和手部动作。文字区占画面约20%到30%。

7. 中文主标题优先6到12字，副标题8到16字，场景标签优先3到6字；英文主副标题不超过6词，场景标签1到4词。移动端可读，不使用过小文字。

8. 不得编造价格、折扣、赠品、认证、检测报告、销量、强功效、绝对化表达或平台背书；不得出现水印、二维码、联系方式、站外导流、其他品牌标识。

**输出要求：**

仅输出一段可直接用于生图的最终提示词正文，保留字段：\[第5屏\]、\[氛围/风格\]、\[元素布局\]、\[光影质感\]、\[配色色系\]、\[视角构图\]、\[文字版式\]、\[比例分辨率\]；字段要求同第1屏，最终输出约400字以上。

在\[第5屏\]中写清产品名称、场景氛围图和唯一场景选择逻辑。

在\[元素布局\]中写清参考产品图、商品位置/大小/角度、使用状态、人物动作或道具互动、至少3种环境元素，并落实上游「人物/道具建议」。

在\[视角构图\]中写清单一沉浸式场景构图、主体占比、留白、视觉动线和区别于首屏的产品角度。画面自然满铺，边缘干净，不生成外框、白边、衔接色块或渐变底条。
