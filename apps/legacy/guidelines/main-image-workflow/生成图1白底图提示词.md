# 生成图1白底图提示词

以下要求直接输出一段完整的提示词。

**要求：**

1.  须先读取《平台品类规则》的「图1｜白底图」规划；提示词主体必须使用中文，并执行图位规划中的平台要求、核心视觉、展示视角、品类策略和背景/风格。
    
2.  你需要完成的事：根据「图1｜白底图」规划生成第1张白底主图提示词。画面以纯白或接近纯白的干净背景展示商品整体，突出产品外观、材质、颜色、结构和完整轮廓。
    
3.  白底图一律不要任何画面文案、标题、副标题、卖点、标签或促销元素；跨境/Amazon按纯白背景合规执行，不加任何投影、无关道具和场景元素；国内平台默认保留自然柔和的产品落地投影，增强真实质感，但仍不得添加文案。
    
4.  产品外观必须与输入产品图一致，并执行图位规划中的「展示视角」；图1展示角度可优先接近原图，仅当原图透视变形严重时才矫正为正常透视视角；不得修改颜色、材质、结构、比例关系、按钮、接口、配件形态和关键细节，不得压缩、拉伸、挤扁、拉宽或改变自然结构。
    
5.  白底图必须突出产品主体，画面干净，主体完整清晰，不遮挡、不裁切、不变形。
    
6.  白底图不调用画面文案，不输出任何文字版式内容；只根据图位规划描述产品主体、背景、投影和构图关系。
    
7.  最终提示词控制在300-600字左右，信息完整但避免冗长。
    

**输出要求：**

仅输出一段可直接用于生图的最终提示词正文，内容不要包含说明性前后缀；提示词主体使用中文，并按以下结构组织在同一段里：

\[主图-1\] 用简洁主题描述白底图与产品；

\[氛围风格\] 写清白底、干净、精修质感、真实商品摄影、品质感、合规克制和品类气质；

\[画质\] 写清商业摄影质感、光线柔和通透、产品清晰真实、画面干净高级、边缘无毛边、无水印无杂物；\[元素\] 写清产品主体位置、大小、摆放角度、完整展示要求、配件是否出现，保持产品外观（物理结构、材质质感、颜色）与输入产品图绝对一致，杜绝任何变形和色差，精细化处理，商品主体占比严格控制在60%-80%；

\[光影\] 写清主光、辅光和材质高光，国内平台保留自然柔和落地投影，跨境/Amazon写清无任何投影；

\[配色\] 写清白色背景、产品主色和少量辅助色，色彩干净不偏色；

\[视角构图\] 写清视角、居中关系、主体占比、留白和轮廓完整不裁切，产品角度优先与原图一致，原图透视严重变形时才矫正为正常透视；

\[文字版式\] 明确无任何画面文案、标题、副标题、卖点、标签、贴纸或促销元素。
