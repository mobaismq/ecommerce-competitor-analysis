# 生成图2场景图提示词

按以下要求直接输出一段完整的提示词。

**要求：**

1. 须先读取《平台品类规则》的「图2｜场景图」规划；提示词主体必须使用中文，并执行图位规划中的平台要求、核心视觉、展示视角、品类策略、背景/风格、人物/道具建议、版式/文字排版和画面文案。

2. 你需要完成的事：根据品类和平台生成第2张场景图提示词，展示商品在真实或风格化使用环境中的状态，实际图位类型可为生活场景图、人物使用图、家居空间图、食用场景图、上身/穿搭图或商务出行图。

3. 产品外观必须与输入产品图的设计和关键特征一致，不得修改颜色、材质、结构比例关系、扶手/靠背/坐垫/瓶身/包装/五金等关键细节；须执行图位规划中的「展示视角」，可根据场景需要调整远近、摆放位置和主体大小，但不得为了排版留白而压缩、拉伸或挤压主体。

4. 场景必须符合品类策略、平台调性和产品真实用途，并执行图位规划中的背景/风格、人物/道具建议和版式/文字排版；保持输出结构不变，先把「品类策略」转成该品类适配的展示方式、道具/人物、信息模块和文字位置，再填入\[元素\]、\[视角构图\]、\[文字版式\]；可用生活使用、桌面/空间氛围、真人/手部互动、原料道具、穿搭上身、厨房/清洁流程等方式，不把所有品类都做成通用静物背景；必须是单一完整场景铺满画面，写清具体空间、材质层次、道具前中后景、人物动作、光影和产品使用关系，至少包含空间/桌面基底、1-3个辅助道具、光源方向、背景虚实层次，不做三分栏、宫格、多场景拼接或卡片分块；产品必须是第一视觉中心，不得因文字区或道具布置被压缩成小摆件。

5. 画面避免错配、不夸张；展示视角按图位规划执行，并写清全景/近景/特写、远近关系和自然透视，不自行改回默认正面角度；可使用克制的风线、水流、光效、声波、科技圆环、粒子或半透明路径辅助展示场景中的卖点或功能，但不得遮挡产品主体、改变产品结构或替代真实场景；如果缺少具体场景，从品类规则和产品用途选择最常见、最安全的通用使用场景。

6. 调取图位规划中的「画面文案」，场景图文字结构固定为主标题+副标题+底部短卖点组，不显示“Slogan”字样；底部短卖点可放3-4条，每条中文最多8字、英文1-3词，只写场景体验、氛围利益或使用感受，不写功能参数、部件名、操作说明、引线说明或图标解释；可按下方文字版式要求适当补充以辅助排版，但不得脱离图位规划事实；必须按字数、语种和断行规则二次压缩，不得照搬超长原句。

7. 优先执行图位规划中的「版式/文字排版」；若规划未指定，再按画面条件从3种预设版式中选择1种，不固定使用第一种：版式1为上下结构，画面上方放主标题+副标题，底部横向宽幅排列3-4条短卖点，底部信息条约占画布宽度70%-85%；版式2为左右结构，在左侧或右侧干净阅读区放主标题+副标题，底部按同一对齐方向排列3-4条短卖点；版式3为角落悬浮结构，主标题+副标题放在左上/右上干净区域，底部或靠近产品的短信息条放3-4条短卖点但不遮挡主体；文字悬浮于干净阅读区，不叠在产品、手部、模特面部或关键场景细节上，不做半屏硬分割、纯色大底框或贴边通栏。

8. 最终提示词控制在300-600字左右，信息完整但避免冗长。

**输出要求：**

仅输出一段可直接用于生图的最终提示词正文，内容不要包含说明性前后缀；提示词主体使用中文，并按以下结构组织在同一段里：

\[主图-2\] 用简洁主题描述场景图与产品体验；

\[氛围风格\] 写清生活方式感、真实感、平台调性、品类气质和场景情绪；

\[画质\] 写清商业摄影质感、光线柔和通透、产品清晰真实、画面干净高级；

\[元素\] 写清产品位置、大小、摆放角度、单一完整场景、前景中景背景细节、道具层次、人物外形衣着姿态/手部动作/使用瞬间；保持产品外观（物理结构、材质质感、颜色）与输入产品图绝对一致，杜绝任何变形和色差，精细化处理；商品主体占比严格控制在60%-80%，画面元素须丰富且不抢主体；

\[光影\] 详细描述主光、辅光、点缀光、光源方向、阴影层次、材质高光和背景虚实；

\[配色\] 写清主色调与辅助色，色值从产品和场景取色，背景主色、辅助色、文字强调色、标签/色块色都取产品主色系；浅色背景使用产品主色的深色版本作主标题/标签/引线，暗色背景使用白色或产品主色的浅色版本作文字，避免无关联黑灰色主导信息模块；

\[视角构图\] 写清平视/俯视/45度等视角、全景/近景/特写、主体占比、前中后景、留白和景深，场景需铺满全屏，不做三分栏、宫格、多场景拼接或卡片分块；

\[文字版式\] 必须执行并展开图位规划中的「版式/文字排版」，直接写出主标题、副标题和3-4条底部短卖点，不出现“Slogan:”或“Slogan”字样；底部短卖点只写场景体验、氛围利益或使用感受，不写功能参数、部件名、操作说明、引线说明或图标解释；主标题为最大字号，副标题约为主标题40%-60%，二者组成同一文字组，边距统一；底部短卖点组横向排布，整体宽度约画布70%-85%，可用细线图标、短竖线、轻量胶囊或半透明柔和渐变承载，避免贴边；文字区面积建议不超过画面30%，不遮挡产品主体和模特面部；文字需放在干净低干扰的阅读区，背后不得有影响识别的主体、道具、纹理、强光影、线条或复杂背景；必要时通过构图、虚化、柔和渐变或移开干扰元素预留阅读区，不用大面积硬色块；明确写出主标题色、副标题色、标签色、色块色和引线色，整体使用产品色系，按背景明暗选择深色字或浅色字；若图位规划未指定版式，按画面条件选择版式：版式1为上下结构，上方放主标题+副标题，底部横向排列3-4条短卖点；版式2为左右结构，在左侧或右侧干净阅读区放主标题+副标题，底部按同一对齐方向排列3-4条短卖点；版式3为角落悬浮结构，主标题+副标题放在左上/右上干净区域，底部或靠近产品的短信息条放3-4条短卖点但不遮挡主体，形成“主标题+副标题+底部短卖点组+产品主视觉”的完整电商层级；信息模块需清晰可读，不得做成蚂蚁字，需放在干净阅读区，不遮挡产品、模特和关键场景；不使用大红框、随意描边框、大面积纯色底框、硬分割版头或一边纯色底一边产品的半屏分割。
