# 输出「效果对比图」的生图提示词

按以下要求直接输出「效果对比图」的生图提示词。

**要求：**

1. 本提示词作为独立节点使用，仅读取《平台品类规则》的「详情页总规划」和「效果对比图」规划，必须使用其中所有字段；不重新规划模块。

2. 本模块负责展示使用前后、整理前后、清洁前后、安装前后、容量前后、细节差异、材质对比、状态变化、口感/质地对比或适配效果，用真实视觉差异强化购买理由。

3. 对比对象只能是本产品使用前后、同一商品不同状态、同一套装内部差异、用户明确提供的适配对象或品类常见使用状态；不得贬低竞品，不得出现“比某品牌更好”“行业第一”等无依据比较。

4. 实物商品必须严格参考用户上传产品图，保持包装、本体、颜色、材质、结构比例、标签、接口、按钮、缝线、轮廓和关键设计特征一致；对比前后不能把商品改款、变形或夸张到不真实。

5. 数字、百分比、测试结果、性能提升、清洁率、承重、防水、续航、营养变化、功效结论必须来自用户信息或包装可见信息；缺少数据时只做视觉状态对比，不编造数值。

6. 文字必须使用《平台品类规则》中本模块的「图位文案」，可用左右对比、上下对比、滑杆式分割、前后标签、局部放大或结果卡片；文字短、清楚、移动端可读，不遮挡对比重点。

7. 必须遵守目标平台规则，不出现虚假价格、虚假折扣、销量误导、评分评价误导、竞品贬低、外链、二维码、联系方式、平台标志仿冒、医疗治疗承诺或未证实强声明；Amazon 额外禁用价格、折扣、销量、评分、评价和 Amazon 页面元素。

**输出要求：**

仅输出一段可直接用于生图的最终提示词正文，保留字段：\[第9屏\]、\[氛围/风格\]、\[元素布局\]、\[光影质感\]、\[配色色系\]、\[视角构图\]、\[文字版式\]。最终输出约400字。

\[元素布局\]写清对比对象、对比前状态、对比后状态、产品位置、局部证据或结果承托；

\[视角构图\]写清左右/上下/滑杆/局部放大的对比结构、阅读动线、留白和不夸张的真实差异。
