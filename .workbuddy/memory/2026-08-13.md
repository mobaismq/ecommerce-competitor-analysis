## 选择AI报告下拉"点击外部自动收起"修复
- 用户反馈：在 `/product-sets` 和 `/aplus` 打开"选择AI报告"下拉后，鼠标移开 / 点击其他地方，下拉一直不收起
- 原因：`AIReportSelector` 只在选中条目或再次点击按钮时才关闭，没有外部点击关闭逻辑
- 修复：在 `app/src/app/components/AIReportSelector.tsx` 加 `useRef<HTMLDivElement>` + `useEffect` 监听 `document.mousedown`，仅当 `productDropdownOpen` 为 true 时挂载；点击不在容器内则关闭
- 用 `mousedown` 而非 `click`，避免与下拉项 `onClick` 事件竞争
- 验证：vite 编译 `AIReportSelector.tsx` 通过（HTTP 200, size 30509）
