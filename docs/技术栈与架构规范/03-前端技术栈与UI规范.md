## 2. UI 组件库规范（Arco Design）

- **默认采用 Arco 组件**：日常布局（Grid, Layout, Space）、表单（Form, Input, InputNumber, Select）、展示（Table, Card, Tag, Typography, Progress）、反馈（Message, Modal, Drawer, Spin）一律优先导入 Arco。
  ```tsx
  import { Button, Card, Form, Input, InputNumber, Message, Modal, Space, Table, Typography } from '@arco-design/web-react'
  ```
- **严禁私自引入其他重量级组件库**（如 Ant Design、Element、MUI 等），以防样式污染与包体积膨胀。

## 3. 图标库使用规范

本项目同时包含三大图标方案，各自有明确的分工与使用方式：

| 图标库 | 安装包 | 核心定位与使用场景 | 引入与使用方式 |
|---|---|---|---|
| **Arco 官方图标** | `@arco-design/web-react/icon` | **常规业务与组件库首选**：按钮、卡片标题、表单前缀、状态反馈等 | `import { IconThunderbolt, IconCopy } from '@arco-design/web-react/icon'`<br>直接作为 React 组件：`<IconCopy />` |
| **Lucide 图标** | `lucide` | **通用矢量图标定义**：提供丰富的通用 SVG 图标节点元数据 | `import { Eye, EyeOff } from 'lucide'`<br>🚨 **注意**：本项目安装的是基础包 `lucide`（而非 `lucide-react`），导出的是图标数据对象，通常配合 `morphicons` 使用，**不要直接写成 JSX `<Eye />`**！ |
| **Morphicons** | `morphicons` | **动态平滑形变特效图标**：密码显隐切换、展开/收起、播放/暂停等需要弹性变幻动画的高质感交互 | `import { MorphIcon } from 'morphicons/react'`（注意子路径为 `/react`）<br>配合 `lucide` 传入：`<MorphIcon icon={showPassword ? EyeOff : Eye} size={18} spring="snappy" />` |

#### 实战用法示例（引自 `LoginPage.tsx`）：
```tsx
import { useState } from 'react'
import { MorphIcon } from 'morphicons/react'
import { Eye, EyeOff } from 'lucide'

export function PasswordInput() {
  const [showPassword, setShowPassword] = useState(false)

  return (
    <button type="button" onClick={() => setShowPassword((v) => !v)}>
      {/* 图标在 Eye 与 EyeOff 之间具有物理弹性平滑过渡动画 */}
      <MorphIcon icon={showPassword ? EyeOff : Eye} size={18} spring="snappy" />
    </button>
  )
}
```

- 🚨 **严格杜绝“凭空臆造”图标名**：
  - Arco 图标名称遵循其官方导出规范（例如不存在 `IconTruck`，物流/货运可使用 `IconCommon`、`IconSend` 等）；
  - 若在 Arco 找不到对应图标，切勿凭直觉猜测导入，可通过 IDE 自动补全或查阅已安装包导出。

## 4. 动画动效体系规范（Motion 规范）

本项目官方引入 **`motion`**（原 Framer Motion 最新升级演进版，`^13.x`）作为桌面端声明式动效核心引擎：

### 核心引入方式：
```tsx
import { motion, AnimatePresence } from 'motion/react' // 🚨 规范：从 'motion/react' 引入
```

### 经典实战场景范例：

1. **容器或卡片弹性进入动画**：
   ```tsx
   <motion.div
     initial={{ opacity: 0, y: 16, scale: 0.98 }}
     animate={{ opacity: 1, y: 0, scale: 1 }}
     transition={{ duration: 0.25, ease: 'easeOut' }}
   >
     {/* 业务卡片内容 */}
   </motion.div>
   ```

2. **列表筛选重排自动平滑插值（`layout` 魔法）**：
   只需给元素添加 `layout` 属性，当数据过滤或重新排序导致位置改变时，Motion 会自动在 GPU 上计算 FLIP 并平滑滑动物理位移：
   ```tsx
   <motion.div layout className="product-card">
     ...
   </motion.div>
   ```

3. **解决组件卸载/销毁时的离场渐变（`AnimatePresence`）**：
   ```tsx
   <AnimatePresence>
     {visible && (
       <motion.div
         initial={{ opacity: 0, scale: 0.95 }}
         animate={{ opacity: 1, scale: 1 }}
         exit={{ opacity: 0, scale: 0.95 }}
         transition={{ duration: 0.2 }}
       >
         {/* 弹层内容 */}
       </motion.div>
     )}
   </AnimatePresence>
   ```

## 5. Tailwind CSS 与样式规范

- 项目集成了 **Tailwind CSS v4**（通过 Vite 插件 `@tailwindcss/vite` 配置）。
- 可自由使用 Tailwind 的实用类（如 `flex`, `grid`, `gap-4`, `p-4`, `rounded-lg`, `text-sm`, `font-bold` 等）。
- 🚨 **注意 JSX 的 style 属性合规性**：
  - `style` 对象只能传入标准 React CSSProperties。
  - **严禁在 `style` 内混入非 CSS 字段**（例如误将 `truncate: true` 传入 style，单行文本截断请在 className 写 `truncate`，或在 style 写 `{ overflow: 'hidden', textOverflow: 'ellipsis', whiteSpace: 'nowrap' }`）。

## 6. 状态管理与数据流

1. **异步后端数据**：使用 `@tanstack/react-query` 的 `useQuery` / `useMutation`，通过统一客户端 `import { api } from '../api/client'` 发起请求。
2. **桌面端本地系统操作**：通过 `window.desktop.*` 调用 Preload 暴露的系统级能力（文件管理、本地采集任务状态、CDP 自动化）。
3. **全局应用状态**：采用 `zustand` 保持极简纯函数状态切片。

## 7. 🚨 AI 编程避坑指南：Arco Design vs Ant Design 差异

在日常开发与 AI 自动写代码中，**最常出现的 Bug 是把 Ant Design 的习惯套到 Arco Design 上**。以下是必须牢记的差异速查表：

| 组件场景 | 常见错误（Ant Design 习惯）❌ | Arco 正确写法（本项目必须遵守）✅ |
|---|---|---|
| **Modal 弹窗宽度** | `<Modal width={680} />`（报 TS2322 属性不存在） | `<Modal style={{ width: 680 }} />` |
| **Space 布局属性** | `<Space orientation="left" />`（属性不存在） | `<Space align="start" />`（或无需添加） |
| **Form 正则校验规则** | `rules={[{ pattern: /^1\d{10}$/ }]}` | `rules={[{ match: /^1\d{10}$/ }]}` |
| **Progress 进度状态** | `status="active"`（报 TS2322） | `status="normal"` 并增加 `animation` 属性 |
| **Select 格式化** | `renderFormat={(option) => option.label}` | `OptionInfo` 无直接 label，需从数据源读取或 `(option as any)?.label` |
| **Typography 复制** | `<Text copyable={{ orientation: 'right' }} />` | `<Text copyable />` 或使用自定义 Tooltip |
| **空值与类型比较** | `costFields: Array<[string, number]>`<br>`if (val !== '')`（报 TS2367 无重叠） | 标注为 `number \| string \| null \| undefined`，包容表单实际运行时状态 |
