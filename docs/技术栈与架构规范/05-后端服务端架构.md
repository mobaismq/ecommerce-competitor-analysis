# 五、后端（NestJS 服务端）架构

## 1. 核心技术栈清单

| 领域 | 技术 / 库 | 核心作用 |
|---|---|---|
| **核心框架** | NestJS 10 (Node.js 20+) | 模块化服务端架构（Controllers, Services, Modules） |
| **HTTP 引擎** | `@nestjs/platform-fastify` | 高性能、低开销的 Fastify 适配层（非 Express） |
| **持久层 ORM** | Prisma ORM (`@prisma/client`) | 强类型的数据库查询与迁移工具 |
| **关系型数据库** | MySQL 8.0（端口 3308） | 企业多租户业务主数据库 |
| **任务队列系统** | Redis（端口 6380） + BullMQ (`@nestjs/bullmq`) | 分布式异步长任务队列，支持任务重试、进度更新与取消 |
| **安全与鉴权** | `@nestjs/jwt` + bcrypt | 令牌签发、多租户（TenantId）隔离与数据行级守卫 |
| **参数校验体系** | `class-validator` + `class-transformer` | 接口入参 DTO 严格白名单校验与类型自动转换 |
| **结构化日志系统**| `pino` + `nestjs-pino` + `pino-pretty` | 高性能异步 JSON 结构化日志输出 |
| **大模型 SDK** | 统一 Provider Router | 支持 Ark (火山方舟)、DeepSeek、OpenRouter 流水线 |
| **测试框架** | `jest` + `ts-jest` | 服务端业务逻辑全套单元测试与集成测试 |

---

## 2. 数据库与 ORM（MySQL + Prisma）

- **Schema 定义**：`apps/backend/prisma/schema.prisma`；
- **包含核心领域**：
  - 租户管理（`Tenant`）、用户（`User`）、角色权限（`Role` / `Permission`）；
  - 商品主档（`ProductMaster`）、竞品分析报告主子表（`Report` / `ReportProduct`）；
  - 生成资产表（`GeneratedAsset`）、异步长任务记录（`Job`）；
- **数据迁移与种子**：
  - 开发期模型变更：`pnpm --filter backend db:migrate`
  - 幂等数据初始化：`pnpm --filter backend db:seed`
  - 可视化查看面板：`pnpm --filter backend exec prisma studio`（打开浏览器 `:5555`）

---

## 3. 异步任务队列（Redis + BullMQ）

- **长任务与解耦**：耗时较长的大模型图文分析、价格带矩阵聚类、文案多语言翻译统一放入 BullMQ 队列；
- **双进程模式**：
  - **API 进程**（`pnpm dev:backend`）：监听端口 8787，处理轻量 HTTP 请求并向队列投递 Job；
  - **Worker 进程**（`pnpm dev:worker`）：消费队列任务，调用大模型或耗时计算，写入 Prisma 数据库。

---

## 4. 大模型路由与流水线（LLM Provider Router）

- **统一路由网关**：在 `apps/backend/src/reports/` 与 `apps/backend/src/agent/` 中编排 Prompt；
- **多模型提供商接入**：
  - 火山引擎 Ark（视觉分析、大模型深度推理）；
  - DeepSeek（结构化卖点提炼、竞品客评正负情感聚类）；
  - OpenRouter（兜底与国际化大模型调用）；
- **防 Token 消耗红线**：
  - 本地自动化测试必须使用 Mock 返回或固化离线 JSON 响应，严防循环测试消耗真实资费。
