# 六、工程命令与质量门禁

在执行开发、提测、交付或代码审查前，必须熟练掌握并遵守以下工程命令门禁：

---

## 1. 核心命令速查表

| 目标 | 执行命令 | 预期指标 | 说明 |
|---|---|---|---|
| **一键启动全套** | `pnpm dev` | 全部进程正常运行 | 同时拉起 API、Worker 与 Electron 窗口 |
| **全仓类型检查** | `pnpm typecheck` | **Exit code 0, 0 errors** | **极其关键！防止任何 TS 标红报错带入仓库** |
| **单子包类型检查** | `pnpm --filter desktop typecheck`<br>`pnpm --filter backend typecheck` | Exit code 0 | 针对性检查桌面端或后端 |
| **全量单元测试** | `pnpm test` | All passed (100%) | 验证业务核心逻辑防退化 |
| **全仓构建检查** | `pnpm build` | 编译成功无丢包 | 验证生产打包完整性 |
| **环境连通性自检** | `pnpm check-env` | 全部 9/9 绿勾通过 | 检查 Node/Docker/MySQL/Redis/Chrome |
| **数据库初始化/刷新** | `pnpm --filter backend db:seed` | 刷新成功 | 幂等初始化角色字典、超级管理员账号 |
| **数据库可视化** | `pnpm --filter backend exec prisma studio` | 打开 `:5555` 网页 | 图形化查看全部 35+ 张 MySQL 数据表 |

## 2. 标红排查方法：告别逐个文件查找

当在编辑器中发现有文件标红或类型错误时，**严禁逐个文件肉眼查找**：

1. **命令行直接全仓扫描**：
   ```bash
   pnpm typecheck
   ```
   该命令底层执行 `tsc --noEmit`，仅需 4 秒即可列出全仓所有标红文件的文件名、报错行号与具体错误信息。

2. **IDE“问题面板”快捷键**：
   - Mac：`Cmd + Shift + M`
   - Windows：`Ctrl + Shift + M`
   直接在编辑器底部弹开“Problems（问题）”面板，平铺所有错误，双击直达。
