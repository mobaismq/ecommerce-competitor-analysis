# 四、桌面端（Electron 主进程与运行时）架构

## 1. Electron 架构与 IPC 通信

- **主进程（`apps/desktop/src/main/`）**：
  - 管理原生窗口生命周期（`index.ts`）；
  - 拥有 Node.js 完整系统特权，负责拉起子进程（Python）、读写本地磁盘（`collection/<jobId>` 工作目录）；
  - 注册 IPC 事件监听器（`collection-handlers.ts` 等），响应渲染层请求。
- **预加载脚本（`apps/desktop/src/preload/`）**：
  - 使用 `contextBridge.exposeInMainWorld('desktop', ...)` 提供严格白名单隔离的 API 网桥；
  - 严禁向渲染进程泄露原始 Node `ipcRenderer` 或敏感系统句柄。
- **渲染层类型契约（`apps/desktop/src/renderer/src/env.d.ts`）**：
  - 全局声明 `Window.desktop` 对象的 TypeScript 接口；
  - 确保渲染层通过 `window.desktop.collection.status()` 等调用时具备完整代码提示与类型安全性。

---

## 2. 本地轻量数据库（Prisma + SQLite）

- **数据库文件**：`apps/desktop/data/desktop.db`；
- **模型定义**：`apps/desktop/prisma/schema.prisma`；
- **核心作用**：
  - 存储本地店透视 RPA 采集任务历史快照（Job ID、抓取参数、日志尾部缓存）；
  - 支持无网或离线模式下查看历史竞品数据与导出记录；
  - 提供本地与云端 MySQL 数据可选同步网关。

---

## 3. Python 运行时与店透视 RPA 控制

- **脚本路径**：`skills/diantoushi-product-research/scripts/run_diantoushi_rpa_cdp.py`；
- **驱动机制**：
  - 主进程通过 `src/main/python-runner.ts` 寻找内置 Python 运行时（或系统 Python）；
  - 通过 Chrome DevTools Protocol (CDP，默认端口 9222) 挂载接管用户已登录店透视账号的真实 Chrome 浏览器；
  - 自动执行关键词检索、分页翻页、销售数据拦截抓取、导出 Excel 数据流；
- **防爬虫封号铁律**：
  - 本地测试时，优先开启 `fake: true` 或直接读取 `rpa_runs/` 目录的历史离线样本数据；
  - 严禁在单元测试或高频自动化循环中频繁调用真实店透视爬虫，以防账号封禁。
