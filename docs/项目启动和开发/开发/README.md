## 使用约定

1. **先启动**：项目没跑起来先看上级目录 [../项目启动指南.md](../项目启动指南.md)。
2. **先查现有，再写新的**：无论加组件、加工具函数还是加依赖，先按 03 号文档确认项目里没有现成的。
3. **先改对地方**：按 01、02 号文档确认能力归属（本地 worker 还是服务端 backend），避免把能力写错层。
4. **提交前过门禁**：`pnpm typecheck` + 相关单测；Phase 交付前跑一次 `pnpm build`。
5. 规范变化时直接改本目录文档，保持与代码现状一致。
