# 04 代码写法与验证门禁

## 1. 核心写法约定

### 1.1 唯一权威判据（最高优先级）

一个业务状态或数据判定**有且仅有一处权威定义**：

- 状态枚举、判定逻辑定义在能力层（worker capability 或 backend service），渲染层只消费、不私造。
- 前端需要新字段/新状态时，先在能力层补权威定义并走通数据链路，而不是在前端用 `startsWith`/魔法字符串临时拼一个。

### 1.2 分层数据流（桌面端）

```
渲染层 pages/components
   │  调 preload 暴露的 IPC API（账户侧走 renderer/src/api 的 HTTP 封装）
   ▼
主进程 capability-handlers.ts（注册/分发）
   │  IPC（utilityProcess）
   ▼
worker <域>-capability.ts（业务能力权威实现）
   │  Prisma / StorageDriver / AI Provider / RPA 运行时
   ▼
本地 SQLite（data/desktop.db）+ 本地文件（~/.ecommerce、~/ecommerce）
```

写新能力的固定套路（照现有 capability 抄结构）：

1. `worker/protocol.ts` 定义通道与请求/响应类型
2. `worker/<域>-capability.ts` 实现能力
3. `worker/index.ts` 注册
4. `main/capability-handlers.ts`（或对应 handler 文件）接渲染层
5. 渲染层通过 preload API 调用
6. 补/改对应 `*.spec.ts` 契约测试

### 1.3 worker IPC 两条硬契约（有 spec 守护，改前先看）

- worker 通信口必须用 `process.parentPort`（utilityProcess），**不是** `require('electron').parentPort`。
- invoke 必须同步派发（`main/worker-manager.ts` 的契约测试约束），不要在派发路径上加异步等待。

### 1.4 诚实报错红线

外部能力缺失（无 AI Key、无 Chrome、无 Python、采集失败等）时：**如实报错 + 给用户可读的提示文案**。严禁返回假数据、Mock 结果冒充成功；演示数据必须显式标注。

### 1.5 代码风格

- 与所在文件/模块现有风格保持一致（命名、注释密度、错误处理方式），不做无关的顺手重构。
- 注释只写代码本身表达不了的约束（为什么必须这样），不写「这行做了什么」。
- 提交信息：conventional commits + 中文描述，scope 用 `desktop` / `backend` 等，例如 `feat(desktop): 图库支持批量导出`。

## 2. 测试数据红线（防封号、防资费）

- 涉及**店透视（RPA）**与**大模型分析**（Ark / DeepSeek / OpenRouter）的逻辑，本地测试一律使用：
  - `rpa_runs/` 历史离线样本数据，或
  - Mock 模式（配置 `fake: true` / `PLATFORM_MOCK=true` / `VIDEO_PROVIDER=mock` / backend `AI_MOCK_MODEL`）
- 严禁在自动化测试中高频触发真实爬虫或线上大模型。

## 3. 验证门禁（拒绝「理论上正常」）

| 阶段 | 必跑 | 说明 |
|---|---|---|
| 日常改完代码 | `pnpm typecheck` + 相关单测（`pnpm test:desktop` / `pnpm test:backend`，或指定文件） | 秒级~分钟级，防止标红 |
| 交付 / 提交 commit / Phase 收尾 | 上述之外**加跑一次** `pnpm build` | 确认打包无损；平时勿频繁全量 build |
| 涉及桌面端资产/运行时 | `pnpm assets-smoke` | guidelines + runtime 冒烟 |

判定标准以**真实命令输出**为准，不以主观感觉为准；测试失败要如实报告并修复，不允许跳过。

## 4. 敏感信息约定

- 真实密钥（AI Key、淘宝 Key、JWT/DB 密码、OSS Secret）只写各自 `.env`，不进任何被 git 跟踪的文件；`.env.example` 只放占位符。
- 用户 AI 密钥只存本机 `~/.ecommerce/users/<id>/config/ai-self.json`，任何 API/日志不回传明文。
