## 📋 四、 核心需求事项清单 (要做什么)

将本次需求需要实现的功能点清晰条目化列出：

- [ ] **事项 2：数据报表一键导出**（提供导出按钮，可下载完整分析结果表格）
- [ ] **事项 3：导出明细内容完备**（导出的文件须包含商品标题、价格、销量、核心卖点）
- [ ] **事项 4：历史记录留存**（能够查看最近导出的记录与下载历史）

## 🔍 五、 详细功能规则与交互逻辑 (具体怎么运行)

### 1. 界面与展示要素
- 页面中需要展示哪些关键信息？
- 按钮/筛选项放在什么位置？默认状态是什么？（例如：默认显示“全部商品”，默认按销量降序排列）

### 2. 正常操作流转 (用户操作链路)
1. 第一步：用户进入分析详情页，点击【导出数据】操作；
2. 第二步：系统弹出导出选项配置，用户勾选所需字段；
3. 第三步：用户点击【确认导出】，系统提示“正在处理中，请稍候”；
4. 第四步：文件生成完毕，自动触发浏览器下载，页面右上角提示“导出成功”。

### 3. 业务规则与限制条件
- **计算/汇总规则**：例如“平均客单价 = 勾选竞品的总销售额 / 总销量”。
- **数量/范围限制**：单次最多允许导出 5,000 条竞品记录；若超出需限制操作并提示。
- **权限与查看范围**：仅拥有“分析师”或“管理员”角色的成员可看到导出操作。

### 4. 异常提示与特殊情况处理
- **无数据时**：列表展示“暂无符合条件的竞品数据”，操作按钮置灰不可点击。
- **处理超时或失败时**：页面明确提示“网络开小差了，导出未完成，请稍后点击重试”。
- **未勾选数据时**：点击导出按钮提示“请至少勾选一个商品后再执行操作”。

## ✅ 六、 业务验收标准 (怎样算做好了)

功能开发完成后，业务/测试人员依据以下条目进行逐一核验：

- [ ] 1. 登录账号后，在竞品报告页面能够清楚看到【导出数据】功能按钮。
- [ ] 2. 设置不同价格范围筛选后，界面列表只展示符合条件的竞品，统计数值实时对应更新。
- [ ] 3. 点击导出后下载得到的 Excel 表格，表头字段完整，中文与数字内容无乱码。
- [ ] 4. 导出的金额、销量数值与页面展示的数值完全一致。
- [ ] 5. 当没有数据时，按钮置灰且有明确提示文案，页面不会出现任何报错。
