
## 唯一权威判据表 (Predicates)

| 状态名称 (类型) | 权威唯一判定位置 (file:line / 纯函数) | 对外表现 (界面显示 / 接口返回) |
| :--- | :--- | :--- |
| `未开始 (start)` | 数据库无记录 / 初始默认值 | 页面展示初始操作按钮 |
| `处理中 (active)` | `server.js:Lxx` / status === 'processing' | 按钮置灰，展示 Loading / 进度条 |
| `完成 (success)` | status === 'completed' 且 数据非空 | 提示成功，渲染完整结果卡片 |
| `失败 (failure)` | status === 'failed' 或 error_message 非空 | 标红提示错误原因，允许点击重试 |
