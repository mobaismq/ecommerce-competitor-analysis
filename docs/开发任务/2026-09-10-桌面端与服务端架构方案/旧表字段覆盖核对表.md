# 旧 MySQL 表 → 新 Prisma 模型覆盖核对表（2026-09-13）

> 原则：旧表只作为业务逻辑与字段语义参考，不迁移数据；新表由 Prisma 统一管理。

| 旧表 | 新模型 | 覆盖说明 | 结论 |
|---|---|---|---|
| sys_user | User | 账号/手机/邮箱/头像/部门/dataScope/状态/软删 | 已覆盖 |
| sys_dept | Department | 部门树 + tenantId/parentId | 已覆盖 |
| sys_role | Role + UserRole + RolePermission | 租户内角色，逗号权限改为关系表 | 已覆盖 |
| sys_menu / sys_button | Permission | 语义 code + type（menu/button） | 已覆盖 |
| sys_platform | Platform | 平台字典 + enabled | 已覆盖 |
| sys_store | Store | 店铺 + platformId + 授权状态 | 已覆盖 |
| crawl_job | CollectionJob + Job | 统一 RPA 采集/Excel 导入，状态落 Job | 已覆盖 |
| source_file_record | SourceFileRecord | storageKey/mimeType/size/sha256 | 已覆盖 |
| product_snapshot | ProductSnapshot | 竞品快照 + snapshotTime/dataSnapshotDate | 已覆盖 |
| product_sku_snapshot | ProductSkuSnapshot | SKU 快照 | 已覆盖 |
| product_qa_snapshot | ProductQaSnapshot | 问大家 | 已覆盖 |
| product_review_snapshot | ProductReviewSnapshot | 评价/追评 | 已覆盖 |
| market_analysis_run | AnalysisRun | reportNo/reportHash/status/competitorCount/costModelJson/reportJson | 已覆盖 |
| market_price_band_* | AnalysisPriceBand / AnalysisBandProduct / AnalysisBandImage | 价格带/竞品/图 | 已覆盖 |
| market_price_band_product_analysis | AnalysisProductAnalysis | 单商品分析 | 已覆盖 |
| product_main_image_analysis | MainImageAnalysis | 主图 Vision 分析 | 已覆盖 |
| market_main_image_ai_report | AiCallCache | AI 结果缓存 | 已覆盖 |
| media_asset / 页面图片资产 | MediaAsset | 采集图片统一资产 | 已覆盖 |
| market_product_asset / generated_main_image | GeneratedAsset | 生成资产 | 已覆盖 |
| market_listing_generation | ListingDraft | 发布草稿 | 已覆盖 |
| rpa_tasks | Agent + AgentAssignment | Agent 设备与执行分配 | 已覆盖 |
| （新增）Job/JobEvent | Job / JobEvent | 通用任务与事件 | 新增 |
| （新增）ProviderProfile | ProviderProfile | AI 供应商配置实例 | 新增 |
| （新增）ReviewRecord | ReviewRecord | 人工审核三态决策 | 新增 |

## 明确裁剪

- 旧登录会话表/接口以 JWT 替代，不迁移会话数据。
- 旧 MySQL 逗号权限字段（如 `sys_role.menu_ids`）不再使用，全部改为关系表。
- 旧 `AnalysisJob`、`RpaTask` 初版表名废弃，由通用 `Job`、`AgentAssignment` 替代。
