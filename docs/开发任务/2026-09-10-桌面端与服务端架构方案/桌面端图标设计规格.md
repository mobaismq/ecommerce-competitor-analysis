# 桌面端应用图标设计规格（2026-09-13 详细版）

## 1. 源文件怎么画

| 项目 | 要求 |
|---|---|
| 画布 | 1024 × 1024 px |
| 视觉主体占比 | 主体占画布 60%-70%，约 614-716 px 宽度 |
| 安全区 | 四周各留 80-100 px，给系统自动圆角/阴影/裁切留余量 |
| 背景 | 建议带品牌色背景，避免大面积纯白/纯黑在深色/浅色模式下看不清 |
| 圆角 | 主源图不画成品大圆角，macOS 系统会自动套用圆角矩形 |
| 阴影 | 不在源图里画外部投影，由系统统一处理 |
| 图层 | Logo 主体与背景分开图层，方便只导出主体 |

## 2. macOS：交付 icon.icns

`icon.icns` 是多尺寸图片容器，系统按显示位置自动选择尺寸：

| 尺寸 | 实际显示位置 |
|---|---|
| 16×16 | 菜单栏、状态栏 |
| 32×32 | 窗口标题栏、小尺寸 Dock |
| 64×64 | Finder 列表 |
| 128×128 | Dock、访达侧栏 |
| 256×256 | 访达大图标、窗口 |
| 512×512 | 高分辨率 Dock/访达 |
| 1024×1024 | Retina 5K、深色模式适配 |

设计要求：建议按 Apple 风格做成圆角矩形视觉，主体清晰、居中、不裁切、不贴边。

## 3. Windows：交付 icon.ico

`icon.ico` 是多尺寸容器，Windows 按不同场景缩放：

| 尺寸 | 实际显示位置 |
|---|---|
| 16×16 | 窗口标题栏、任务栏小图标 |
| 24×24 | 开始菜单小图标、传统工具栏 |
| 32×32 | 任务栏、开始菜单 |
| 48×48 | 桌面图标、资源管理器 |
| 64×64 | 高 DPI 任务栏 |
| 128×128 | 应用商店、通知 |
| 256×256 | Windows 10/11 应用图标主尺寸 |

建议以 256×256 PNG 作为最大层级；安装包 `.exe` 也使用同一个 `icon.ico`。

## 4. Linux：交付 icons/ 多尺寸 PNG

Linux 不使用容器，直接读取 PNG：

```text
16x16.png
32x32.png
48x48.png
64x64.png
128x128.png
256x256.png
512x512.png
1024x1024.png（可选）
```

AppImage 以 256×256 作为入口图标。

## 5. 设计师交付目录

```text
desktop/build/
├── icon.svg                 # 矢量源文件
├── icon.png                 # 1024×1024 导出稿
├── icon.icns                # macOS
├── icon.ico                 # Windows
└── icons/
    ├── 16x16.png
    ├── 32x32.png
    ├── 48x48.png
    ├── 64x64.png
    ├── 128x128.png
    ├── 256x256.png
    ├── 512x512.png
    └── 1024x1024.png
```

## 6. electron-builder 接入

```yaml
mac:
  icon: build/icon.icns
win:
  icon: build/icon.ico
linux:
  icon: build/icons
```

## 7. 最终交付清单

设计师交付 5 类文件：

1. `icon.svg`（矢量源文件）
2. `icon.png`（1024×1024）
3. `icon.icns`（macOS）
4. `icon.ico`（Windows）
5. `icons/` 目录（Linux 各尺寸 PNG）
